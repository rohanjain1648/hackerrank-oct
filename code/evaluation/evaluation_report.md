## 6. Known limitations

- When several requests share one workflow window and their identifier-less records are rendered identically, the assignment falls back to a deterministic tie-break (earliest activity -> lowest case number); such ties are reported in the per-case trace (`.cache/runs/eval_trace.json`).
- Single-request story cases depend on screenshot transcription. The offline path uses RapidOCR; with `--llm` Claude vision transcribes the screens into the same row format.
- The sample set is small (32 cases), so the workflow-linking signals were checked against the evaluation set's structure (batch evidence files, status mix) and the custom cases as well.
